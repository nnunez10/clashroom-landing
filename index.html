Good questions.

Can I check a claim on this website?

This page introduces the private prototype. You can explore the selected reporting, watch a recorded app check and sign up for beta updates. There is no public claim checker on this page.

Does it check an entire video?

The current prototype checks the exact statement you deliberately submit. A shared post or link provides context; it doesn’t mean the entire video has been verified.

Will it always have an answer?

A check can return no matching review or limited evidence. Inspect the result, its basis and sources. The absence of a match is not proof that a statement is false.

When can I try ClashRoom?

ClashRoom is a private prototype. The interest list is for hearing about beta testing; there is no public launch date yet.
